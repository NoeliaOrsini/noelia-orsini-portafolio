## 💡 Sobre el proyecto
Diseñado bajo una estética corporativa y moderna ("Dark Tech Elegance"), este portafolio refleja una intersección única de alta valorización IT: una sólida trayectoria como desarrolladora Back-End complementada con más de 20 años de experiencia en el ámbito legal y formación en counseling, con un enfoque central en la supervisión ética de la IA (*Human-in-the-Loop*). 

Reúne una selección curada de 9 proyectos clave que abarcan desde agentes autónomos y arquitecturas RAG hasta automatizaciones de cumplimiento normativo y análisis de datos.

## 🚀 Tecnologías utilizadas
- React / TypeScript / Tailwind CSS
- Arquitectura de desarrollo asistido por IA (Lovable)
- Control de versiones y sincronización automatizada mediante Git/GitHub
